Widget Android — Quản trị hệ thống

Tài khoản super_admin · widget màn hình chính · thông báo đơn POS qua server

HDSD v1.3 · App 0.2.0 · Khớp Shop-Manager (QuyLV) · 14/10/2026

Trang này chỉ hướng dẫn quản trị widget. Ghép tablet với quầy (LAN, chụp CK) → Widget · Ghép quầy.
Admin cửa hàng / staff POS không xem được widget tổng quan này.

2. Cài app & URL server

  1. Cài APK VietPOS Widget (bật cài từ nguồn không xác định nếu cần).
  2. Tablet cùng mạng với server VietPOS (Wi‑Fi / LAN).
  3. Chuẩn bị URL do IT cung cấp (Docker/nginx http://IP:8080, dev http://IP:3003, hoặc domain HTTPS production) — không thêm / cuối.
Phiên đăng nhập dùng cookie HttpOnly giống POS web (không cần copy token thủ công).

3. Vào màn Quản trị

  • Màn đầu app → chạm Quản trị.
  • Hoặc menu ≡ → Quản trị (chưa login) / Hồ sơ (đã login).

4. Đăng nhập

  1. Nhập URL, Email, Mật khẩu (giống POS web / Desktop).
  2. Có PIN 4 số: nhập PIN → Đăng nhập. PIN sai → app xóa ô PIN để nhập lại.
  3. Nhập sai PIN nhiều lần: tài khoản khóa PIN tối đa 5 phút (đếm ngược trên POS; trên Widget chờ hết khóa rồi thử lại).
super_admin không có «Quên mã PIN» trên app. Quên PIN quản trị hệ thống → liên hệ vận hành / IT reset (giống POS Desktop).

Sau đăng nhập, app đồng bộ widget (nền ~30 phút/lần và khi mở app). Số liệu «hôm nay» trên server theo lịch Việt Nam (khớp dashboard POS).

5. Thêm widget ra màn hình chính

  1. Giữ icon màn hình chính → Widget → chọn VietPOS (2×2, 2×3, 3×4, 4×2, 4×4, 4×5…).
  2. Kéo widget vào màn hình.

«Mở app để đăng nhập» · «Đang tải…» · có số liệu. Chạm dòng trên widget → mở app.

6. Nội dung widget (cuộn)

  1. Tổng quan — doanh thu, đơn, khách xem, TM/Thẻ/CK, tồn thấp, xu hướng %.
  2. Từng cửa hàng — chuỗi nhiều shop.
  3. Nhập hàng — backlog hóa đơn nhập.
  4. Cần xử lý — VAT, HĐĐT, đặt hàng, nhập hàng, thông báo chưa đọc.

7. Giao diện sáng / tối

Menu ≡ → Giao diện Widget → Hệ thống / Sáng / Tối. Widget chưa đổi màu: mở app hoặc gỡ/thêm lại widget.

8. Thông báo đơn mới

  • Sau khi đăng nhập super_admin trên máy này.
  • Bật quyền Thông báo (Android 13+), kênh «Đơn hàng mới».
  • App poll API định kỳ (~20 giây) — không qua LAN ghép quầy.
  • Nội dung kiểu: Đơn mới {mã} · {shop} — quầy · số món · tổng tiền · (Tiền mặt / Thẻ / Chuyển khoản).
  • Trên POS web, super_admin có thể chỉnh cài đặt thông báo (chuông thông báo → cấu hình loại sự kiện / email) — tablet nhận phần in-app tương ứng server.

9. Đăng xuất

Menu ≡ → Đăng xuất → widget «Mở app để đăng nhập», thông báo đơn dừng. (Cũng hủy ghép quầy nếu máy đang ghép — xem trang Ghép quầy.)
